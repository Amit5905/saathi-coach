# Saathi Coach (demo)
Voice-first AI coach for microfinance loan officers. Built on Gemini Live API + Gemini.

## Run
1. Laptop pe Chrome mein `index.html` kholein (double-click).
2. Gemini API key paste karke Start dabayein.
3. Practice tab: scenario chunein → Call shuru karein → mic allow karein → Hindi mein baat karein.
4. Call khatam → Score karein.
5. Policy Saathi: PDF upload karke sawaal poochein.

Models: gemini-2.5-flash-native-audio (Live), gemini-2.5-flash (scoring, Q&A). Change at top of script if renamed.
